# 编辑器离场统一为三种口径：明确保存 / 明确不保存 / 直接返回

## 目标行为（已与用户逐条确认）

| 离出口径 | 自动保存 **开** | 自动保存 **关** |
|---|---|---|
| **明确保存**：返回确认框点「保存」、编辑器「保存并退出」 | 全部实例落盘 + 全部销毁 | 全部实例落盘 + 全部销毁（现状其余实例会暂存，**需改**） |
| **明确不保存**：返回确认框点「不保存」 | 丢弃不落盘 + 全部销毁 | 丢弃不落盘 + 全部销毁（基本不变） |
| **直接返回（全部统一）**：返回键（无修改）、抽屉去文件浏览/首页/设置/代码表/翻译库/自定义补全、坐标可视化等一切未做明确选择的离开 | 全部实例落盘 + 全部销毁（销毁为新行为） | **暂存**（现状 holdPaths 语义，保持不变；抽屉路径现状会落盘，**需改为暂存**） |

「暂存」= 工作区条目与实例缓冲保留不落盘，下次打开文件原样恢复（含未保存修改标记、光标滚动）。「销毁」= 工作区清空、实例列表清空，重开文件从磁盘干净加载。

## 改动文件

### 1. `MainApp.kt`（主改动）

**a. 新增状态**（`holdPaths` 声明后，约 192 行）：
```kotlin
// 离场销毁标记：明确「保存/不保存」或自动保存开启的任何离开都会置位；
// 由离场 LaunchedEffect 在实例全部销毁（onDispose 上报完成）后清空工作区与实例列表。
var workspaceWipePending by remember { mutableStateOf(false) }
```

**b. 新增离场统一效应**（组合层内、`when(currentScreen)` 之外，`cacheEditorStateBeforeLeave` 附近）：
```kotlin
var lastScreenForEditorExit by remember { mutableStateOf(currentScreen) }
LaunchedEffect(currentScreen) {
    val leftEditor = lastScreenForEditorExit == Screen.EDITOR && currentScreen != Screen.EDITOR
    lastScreenForEditorExit = currentScreen
    if (leftEditor) {
        if (SettingsManager.autoSave) {
            workspaceWipePending = true          // 直接返回（自动保存开）：全部落盘+全部销毁
            holdPaths = emptySet()               // 自动保存模式无「暂存」，清历史残留避免抑制落盘
        } else if (openPaths.isNotEmpty()) {
            // 直接返回（自动保存关）：暂存不落盘，下次打开恢复
            holdPaths = holdPaths + openPaths.toSet()
        }
    }
    if (workspaceWipePending && currentScreen != Screen.EDITOR) {
        workspace = emptyMap()
        openPaths = emptyList()
        holdPaths = emptySet()
        workspaceWipePending = false
    }
}
```
时序依据：实例 `onDispose`（缓存/落盘上报）在组合丢弃阶段同步执行，`LaunchedEffect` 协程在其后运行，此处清空即最终态；`saveWorkspaceEntry` 异步落盘写磁盘不受影响，其写回 `workspace.mapValues` 在空表上为无操作。

**c. 重写 `onBack` lambda**（923-937 行），签名改为双参数：
```kotlin
onBack = { discard, saveAll ->
    val allPaths = openPaths.toSet()
    openPaths = emptyList()
    when {
        discard -> { discardPaths = discardPaths + allPaths; workspaceWipePending = true } // 明确不保存：丢弃+销毁
        saveAll -> workspaceWipePending = true                                            // 明确保存：全落盘+销毁
        !SettingsManager.autoSave -> holdPaths = holdPaths + allPaths                     // 直接返回（自动保存关）：暂存（现状不变）
        else -> {}                                                                        // 直接返回（自动保存开）：由离场效应销毁
    }
    currentScreen = popScreen(Screen.BROWSER)
    selectedFile = null
}
```

**d. `onSaveAndExitDone`**（约 950-960 行）ok 分支加 `workspaceWipePending = true`（保存并退出属明确保存；其余实例仍由 onDisposeFlush 落盘）。

**e. 注释同步**：`holdPaths` 声明（191 行）、`onDisposeFlush`（908 行）、`cacheEditorStateBeforeLeave`（304 行）注释按新口径改写；这些函数逻辑不变。
