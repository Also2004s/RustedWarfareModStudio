# 补全验证清单

> 目的：手工/半自动验证编辑器「值补全」与「补全查看器」行为是否符合预期，防止回归。
> 本清单以当前源码为准；如与线上行为不符，以代码为准并同步更新本文。
>
> 复现入口：**开发者工具 → 补全查看**（CompletionViewerScreen）。
> 演示行默认显示「属性名:」，光标视为停留在行尾；列表按来源分组展示该行光标处可调用的补全值。

---

## 1. 补全查看器（DemoPanel）核心行为

| # | 演示行输入 | 期望结果 | 说明 |
|---|---|---|---|
| 1.1 | `ammo:`（或任意匹配不到属性的名字） | **无可补全项**（空列表），且**不**出现「所有类型」全量条目 | 回归目标：DemoPanel 必须按当前属性行上下文过滤真实值补全；此值会随界面上方分类浏览(CallableCategoryBrowser)共存 |
| 1.2 | 某个真实属性名 + 冒号（如 `需要条件:`、`用逻辑设置资源:`) | 按该属性值类型触发对应的补全（如 布尔值/逻辑表达式/动态资源等） | 只应出现该属性实际可补全的值类型 |
| 1.3 | 演示行内容改动后 | 补全列表随 `demoText` 变化实时重算，不残留旧上下文的全量项 | 由 `remember(demoText)` 驱动 |
| 1.4 | 点击某补全项 | 按当前可替换片段长度（valuePrefixLength）回填到行尾，与生产替换语义一致 | 保留现有交互 |

**判定标准**：DemoPanel 不再使用 `getAllCallableItems()`（全量、与上下文无关）；改用 `getValueCompletionsGrouped(...)`，空结果的 Provider 不输出。

## 2. 值类型补全场景（在生产编辑器或查看器验证）

> 「需节」列：填当前所在节（如 `[核心]`），无关节传 null（查看器允许空节时遍历全部节兜底查找）。

| # | 场景 | 输入 | 期望出现的补全（中文视图） |
|---|---|---|---|
| 2.1 | 纯布尔值属性（节=`graphics`/`leg_arm`，填 `真/假`） | `锁定主体旋转随主炮塔:`（或 `锁定运动:`） | `真`、`假`（**不**出现 `true`/`false`，**不**因二次翻译回英文） |
| 2.1b | 逻辑布尔 可 if（节=`action`，`LogicBoolean`） | `锁定:` | `if`、比较符、布尔函数、`or/and`（`真/假` 也在候选）。参考实际项目 `锁定:if 全图中此单位数量(需标签="前线", 范围内=320, 少于=1)` |
| 2.2 | 逻辑数值属性 | `自身血量:` | 数值类逻辑表达式、`self.xxx` 无参 getter、带参函数（带 `(`） |
| 2.3 | 逻辑布尔（条件） | `需要条件:` | `if`、比较符上下文、布尔函数、`or/and` |
| 2.4 | 单位标记表达式 | `设置单位内存:目标=` | `self`、`事件来源`、`最后伤害源`、`创建标记(`、`接近单位(` 等（`isUnitMarkerType` 类型） |
| 2.5 | 单位类型引用 | `产生单位:` | 单位类型名（如 `builder`、`猛犸坦克T1`），非单位标记表达式 |
| 2.6 | 动态资源 LHS | `资源名=` | 资源名补全为 `资源名=` |
| 2.7 | 动态资源/内存 RHS | `AI阶段=` | RHS 走内存/逻辑表达式补全，不混淆 LHS |
| 2.8 | 函数参数括号内 | `自身弹药包括队列(` | 命名参数（`lessThan=`/`greaterThan=` 等），不全表刷 KEY |
| 2.9 | 插值 `${` | `范围内=${攻击.攻` | 全量逻辑表达式（剔除运算符/`if`/`memory.NAME` 占位），不清空已输入资源名 |
| 2.10 | 值片段 `.` 链 | `自身资源.最新编号` | 资源链补全，不被通用 KEY/翻译库兜底覆盖 |

## 4. 自查步骤（改补全功能后必跑）

1. 打开「补全查看」，确认 场景 1.1：输入 `ammo:` 显示「无可补全项」。
2. 依次在演示行验证 2.1–2.10，确认补全值与类型符合上表，且无英文残留。
3. 全局浏览不受影响：顶部进入「单位标记/数值表达式/布尔值/连接符/运算符/任意类型」分类，仍能浏览全量条目（走 `CallableCategoryBrowser`/`getAllCallableItems`）。
4. 落库验证：`.\gradlew.bat assembleDebug` 编译通过后安装，手动走完上述场景。
