## ✅ 已修：字段列表打空格会写出空格分隔的错值

**你敲**：

```
转换时保留字段:装甲 （末尾一个空格，想接着填第二个字段）
```

**改之前**：直接弹字段列表，一选变成 `装甲 生命值`——空格隔开，游戏不认（应该用逗号）。
**改之后**：打空格只弹「,」，点了变 `装甲,`，继续补下一个字段。和复制与同一条规矩。

受影响：转换时保留字段、whenBuilding_temporarilyConvertTo_keepFields 两个键。
**设置单位状态 故意不修**：它的写法是 `护盾值 += 20`，空格是「字段」和「+=」之间的合法分隔，打空格弹「,」会把你要敲的加号拦住。

**怎么验**：敲 `转换时保留字段:装甲 ` → 只弹「,」；敲 `设置单位状态:护盾值 ` → 照常弹字段/运算符（不该变）。

## 🟢 枚举值有一小撮补全弹的是英文（显示不统一，能用）

**你看到的现象**：大部分枚举值补全弹出来是中文（比如运动类型弹「陆地/空中/两栖」），但个别值弹的是英文原文：

- 被运输单位类型限制：`BUILDING`（建筑）、`OVER_WATER_CLIFF`（越过水上悬崖）——同表其他 5 个值都有中文，就这俩没有
- 优先级：`veryLow / low / normal / high / veryHigh / critical` 整组无中文
- 队伍着色模式：`pureGreen / hueAdd / hueShift / disabled` 整组无中文
- 还有零星几个：绘制层（wreaks/bottom 等）、动作时机（idle/repair 等）、新地图出生点整组、数字分组（none/comma/space）

**为什么**：这些值的中文翻译在词典里漏登记了。补全照常工作，插进去的都是游戏认的英文值，**只是弹窗里看不懂英文的人少了提示**。全项目合计约 60 个值，其余 150+ 条"没翻译"经逐类甄别都是**本来就该保持英文**的（逻辑表达式、运算符、内置图像集名、函数名），不是缺口。

**改之后（如果修）**：词典补登记后，这几个值也弹中文，和其他值统一。

## 🟡 登记一条译名分歧：官方文档的「水面」对不上

官方文档示例写 `被运输单位类型限制: 空中, 水面`。App 词典里「两栖」= hover、「水面」= water。但这个键的合法值表里**没有 water**，有 hover。也就是说：照官方文档手打「水面」，反译出来是 water，而这个位置真正该填的是 hover（App 里叫「两栖」）。

这是官方文档措辞、游戏实际值、App 译名三方不一致。**修法需要老板定**：把 hover 的译名从「两栖」改成「水面」，还是保持现状不管。
