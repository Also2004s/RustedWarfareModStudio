## 修复：文件浏览器第二次进入时「更多」菜单自动展开
- 根因：`FileBrowserScreen` 用 `LaunchedEffect(toolMenuTick) { if (toolMenuTick > 0) showToolMenu = true }` 响应全局菜单栏的「更多」。tick 一旦 > 0（点过一次「更多」），之后每次重新组合本页（从首页/编辑器再进浏览器）都会命中这个条件 → 自动弹菜单。单栏同样中招，不只是双栏。
- 修法：加 `lastToolMenuTick`（`remember { mutableIntStateOf(toolMenuTick) }`），首次组合时把当前 tick 记为已消费，只对 tick **变化量** 响应。`FileBrowserScreen.kt:172-182`。
