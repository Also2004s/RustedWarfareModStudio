## 修复：`用逻辑设置资源:"""..."""` 多行值块续行 `资源名=` 后不弹表达式补全

- **现象**：`用逻辑设置资源`（dynamicresources）多行值块内，续行 `随机次数=` 的 `=` 之后不弹表达式补全（int/rnd/自身资源.x 等），但 LHS 资源名补全正常。
- **根因**：`LogicBooleanValueCompletionProvider.canProvide()` 对 dynamic-like 属性 RHS 判定用 `currentSegmentRhs(textBeforeCursor)`，该函数依赖行内 `:`；多行值块续行无 `:` → 判定失败 → canProvide false → `shouldSuppressEmptyValueFallback` 返回空列表。
- **修复**：`LogicBooleanValueCompletionProvider.kt` 新增 `isDynamicLikeRhsLine()`：`currentSegmentRhs != null || (行无冒号 && topLevelEq >= 0)`；canProvide 中 dynamicresources/kvp/fieldsValues 三处 RHS 判定统一改用它。LHS（无 `=`）不误判；括号内命名参数 `=` 被 topLevelEq 跳过。
- **构建**：`assembleDebug` 成功（3m45s），adb install -r 已装到设备。

## 修复（第二轮）：点击 资源名= 后不立即弹表达式补全 —— 编辑器侧触发门槛

- **现象**：提交（点击）`资源名=` 补全后，窗口关闭但**不立即**重弹表达式补全；用户需再敲字符才弹。
- **根因**：`SoraCodeEditor.kt` 三处补全重触发门槛都要求 `line.indexOf(':') > 0`（activeProbeTrigger、SelectionChangeEvent、ContentChangeEvent）。多行值块续行无 `:` → 提交后重触发被跳过。
- **修复**：`SoraCodeEditor.kt` 新增 `isMultilineBlockValueRhs(editor, line, col)`（行无冒号 && 行内顶层 `=`（topLevelEq，括号内命名参数跳过）&& `multilineValueOwnerKey(整段文本到光标)` 命中未闭合多行值块）；三处门槛改为 `行有冒号 || isMultilineBlockValueRhs`。sora API：`Content.getCharIndex(line,col)` / `Content.substring(start,end)`。
- 至此两端闭环：provider 侧（canProvide 识别无冒号续行 RHS）+ 编辑器侧（提交后重触发放行）。`assembleDebug` 成功，adb 已装。

## 修复：保存大文件仍卡 ~0.6s —— `sameContent`/`computeLineDiff` 的 LCS 是元凶

- **现象**：右上角保存按钮对 ~12KB 文件仍卡 0.6-1s（第一次已修掉全量净零检查，但只查当前文件仍慢）。
- **定位**：写文件耗时日志到 `/sdcard/RWmod/save_timing.log`（vivo 过滤 logcat，改用文件日志），`[DrawerAutoSave] record=976ms`：其中 `netzero=475` + record 开头 `sameContent(before,after)` 约 475，两笔都是 LCS。
- **根因**：`SaveHistoryManager.sameContent` 字符串不等时走 `computeLineDiff`（LCS O(m×n) 动态规划）；且 DP 内层循环每次比较都调用 `normalizedForDiff()` 重新 filter 生成新字符串，大文件几百 ms。
- **修复**：
  1. `DiffUtil.computeLineDiff`：预计算 `nb/na`（每行归一化一次），DP 循环与回溯直接比较数组，语义不变；
  2. `SaveHistoryManager.sameContent`：`a==b` 快路径后加**快速否定** `a.normalizedForDiff() != b.normalizedForDiff()` 直接 return false（逐行归一化相等 ⇒ 全串去空白相等，逆否成立），大多数真改动的保存 O(长度) 返回，不进 LCS；只有「去空白后相同但行切分不同」才走 LCS。
  3. `normalizedForDiff` 由 private 改 internal 供 SaveHistoryManager 复用。
- **清理**：移除 EditorScreen.saveSync / MainApp.saveWorkspaceEntry / saveAllWorkspaceFiles / SaveHistoryManager.record 里的全部计时+appendText 调试日志。
- **构建**：compileDebugKotlin 通过；installDebug 遇杀软锁 `mergeProjectDexDebug/classes.dex`，`--stop` + 删 `app/build/intermediates/dex/debug/mergeProjectDexDebug` 后重试成功，已装到设备。
- **后续验证**：用户实测大文件保存是否回到毫秒级（翻译+写盘约 20-70ms 为正常）。
