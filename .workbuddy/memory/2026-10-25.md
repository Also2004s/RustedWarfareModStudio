## 11:36 追问「绕路 ≤ 直连」的严格区域 + 加零区域/满屏提示
- 老板要画 `间距(self,A)+间距(A,B) <= 间距(self,B)`（预设一去掉容差）。
- 结论：三角不等式左边恒 ≥ 右边，等号只在 **A 落在线段 S-B 上**时成立 → 严格区域是从 A 出发、背离 S 的一条**零宽度射线**（B 在 A 外侧）。B 在 S、A 之间反而更不成立。
- 数值：S=(0,0) A=(250,0)，B=(600,0) → 600=600 ✔；B=(600,10) → 左 600.14 > 右 600.08，差 0.06 就不成立（容差 4 才算成立）。
- 因此这类公式在采样可视化里必须给容差，否则一格都采不到 → 在 `SimAnimScreen` 左上图例下加了两条自动提示：
  - `coverage <= 0.0005` → 「区域为空：等号类公式只在一条线上成立，把容差调到 3~8 才看得见」
  - `coverage >= 0.995` → 「铺满视图：这条公式在当前场景下恒成立，没有约束力」
