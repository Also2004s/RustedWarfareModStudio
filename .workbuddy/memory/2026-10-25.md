## 11:15 仿真动画引擎（新功能，已编译打包）
- 老板要：开发者模式里开一个「仿真动画引擎」，能把公式表达的区域画出来（例：`间距(self,当前动作目标)+间距(当前动作目标,活动路径点目标) <= 间距(self,活动路径点目标)`），基于坐标可视化做，顺手优化坐标可视化。
- 新增 `feature/coord/CoordSim.kt`：`SimMotion`(Still/Circle/Path) + `positionAt` 插值 + `RegionMask` + `sampleRegion` + `splitTopComparison` + `evaluateReadout` + `SIM_PRESETS`(4 个)。
- **核心机制**：`EvalContext` 加 `probeName/probeX/probeY`（自由变量覆盖），逐格采样时只 `copy` 上下文、不复制 targets 表；公式顶层是比较运算时拆成左右两式分别求值 —— 这样才能加「容差」（等号类公式的区域是一条零宽度的线，没容差采样采不到，这是这个功能能成立的关键）。
- 渲染：掩码烘成 `IntArray→Bitmap→ImageBitmap`，画布用 `drawImage(filterQuality=Medium)` 缩放贴图（比画几千个矩形快，边缘也柔和）。`CoordCanvas` 新增 `regionMask/regionImage/regionAlpha` 三个可选参数。
- 采样成本控制：格数固定上限约 9000（`cols≈sqrt(9000/aspect)`），与画布像素无关；动画 60fps 但区域重算节流到 ~80ms 一次（`regionTick = simTime/0.08`）。
- 新页 `ui/screens/SimAnimScreen.kt`：时间轴(播放/暂停/0.5-2x/重置)、场景下拉、公式输入、自由变量下拉、容差滑杆(0~40)、左下图例、右下实时判定与左右值；拖动目标 = 该目标转静止（手动优先于预设运动）。
- 入口：开发者模式新增「仿真」分区 → 「仿真动画」；`Screen.SIM_ANIM` + 顶栏标题 + 宽度白名单（全宽）。
- 坐标可视化顺手优化：`drawGrid` 增加**网格刻度数字**（贴屏幕左侧/底部，格距小于阈值自动跳标 2/5/10 格），两个页面共用。
- 已知未做：只支持单个自由变量（无参数扫描）、区域无边界描边、运动路径点不能在 UI 里编辑、场景不持久化。
